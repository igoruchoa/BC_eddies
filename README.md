# BC_eddies
Uses the META3.1exp eddy detection product for mesoscale eddy analysis in the Brazil Current

## track_analysis.py
Delimits a known area and analyzes the mesoscale eddies within the area distinguishing between polarity (cyc/anticyc).

## track_analysis_specifics.py
Uses a region of formation for the selected eddy,computes mean parameters and plots the track of the selected eddy.
